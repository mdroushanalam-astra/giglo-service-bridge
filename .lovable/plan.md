

# Giglo Investor Pitch Deck — Interactive Animated Presentation

## Overview
A full-screen, slide-by-slide animated pitch deck built as a web app. Vibrant & energetic design using Giglo's brand colors (orange #F5A623, charcoal gray #4A4A4A, white). Arrow key and click navigation. Heavy use of animated diagrams, charts, icons, and minimal text — designed to psychologically engage top-tier VCs.

## Design & UX Details
- **Colors**: Orange (#F5A623) as primary accent, Charcoal (#4A4A4A) as text, white backgrounds with orange gradient accents
- **Navigation**: Left/right arrow keys, on-screen arrow buttons, slide indicator dots at bottom
- **Animations**: Typewriter text, staggered fade-ins, counter animations for stats, diagram build-ups, card flips, progress bar fills
- **Typography**: Bold headlines, minimal body text — visuals do the talking
- **Charts**: Animated recharts for data visualizations (market size, comparisons)
- **Psychology**: Contrast (problem vs solution), progressive disclosure, emotional hooks, visual metaphors (broken bridge), social proof via numbers
